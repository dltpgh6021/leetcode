# 0002. Add Two Numbers

* **Difficulty:** Medium
* **Problem:** https://leetcode.com/problems/add-two-numbers/

---

## Problem Summary

역순으로 입력되어 있는 두 연결 리스트(Linked List) 형태의 정수를 더하여, 그 결과를 다시 역순의 연결 리스트로 반환한다. 
리스트의 맨 앞 노드가 숫자의 '일의 자리'를 의미하므로, 두 숫자를 원본 정수로 변환할 필요 없이 **앞에서부터 차례대로 더하며 올림수(Carry)만 처리**하면 된다.

---

## Approach

### Solution 1. Iterative Addition (반복문을 이용한 자릿수 덧셈)

#### Idea

초등학교에서 덧셈을 배울 때 일의 자리부터 차례대로 더하며 10이 넘으면 다음 자리로 올림수(Carry)를 넘겨주는 방식과 완벽히 동일한 원리를 사용합니다. 결과 리스트의 시작점을 쉽게 잡기 위해 **더미 노드(Dummy Node)**를 활용하면 코드가 훨씬 간결해집니다.

#### Algorithm

1. 결과 리스트의 시작을 잡아줄 가짜 노드인 `dummy` 노드를 생성하고, 새 노드를 이어붙일 포인터 `curr`를 `dummy`로 설정합니다.
2. `l1`, `l2` 노드가 남아있거나, 아직 처리해야 할 올림수(`carry`)가 남아있는 동안 `while` 루프를 반복합니다.
3. 현재 `l1`, `l2`의 값과 `carry`를 모두 더합니다. 
   - 10으로 나눈 몫은 다음 자리로 넘길 올림수(`carry = sum / 10`)가 됩니다.
   - 10으로 나눈 나머지는 현재 자리에 들어갈 숫자(`sum % 10`)가 됩니다.
4. 계산된 나머지 값으로 새 `ListNode`를 생성하여 `curr->next`에 연결하고, `curr`, `l1`, `l2` 포인터를 각각 다음 노드로 이동시킵니다.
5. 루프가 종료되면 `dummy->next`를 결과로 저장한 뒤, 메모리 누수 방지를 위해 `dummy` 노드를 할당 해제(`delete`)하고 결과를 반환합니다.

#### Complexity

* **Time Complexity:** O(max(M, N))
  - M과 N은 각각 `l1`과 `l2`의 길이입니다. 두 리스트 중 더 긴 리스트의 길이만큼 반복문이 실행됩니다.
* **Space Complexity:** O(1)
  - 결과를 담기 위한 새로운 리스트 생성 비용을 제외하면, 올림수를 저장하는 변수 등 상수 크기의 추가 메모리만 사용됩니다. (결과 리스트까지 포함할 경우 O(max(M, N)))

## Learned

* **더미 노드(Dummy Node) 패턴:** 연결 리스트의 헤드(Head)를 조작해야 할 때, 빈 노드를 맨 앞에 두면 첫 번째 노드를 삽입할 때의 예외 처리를 없애 코드를 간결하게 만들 수 있습니다.
* **C++ 동적 할당과 포인터 이동:** `new`를 통해 힙 메모리에 노드를 생성하고 연결하는 방법, 그리고 `curr = curr->next`를 통해 포인터를 순회하는 링디드 리스트의 기본 조작법을 익혔습니다.
* **메모리 관리:** C++에서는 가비지 컬렉터가 없으므로 임시로 사용한 `dummy` 노드는 반환 전 반드시 `delete`로 메모리를 해제해 주어야 좋은 코드가 됩니다.
