# LeetCode Solutions

꾸준한 알고리즘 학습과 코딩 테스트 준비를 위해 LeetCode 문제 풀이를 기록하는 저장소입니다.

## 📌 Goal

* LeetCode 문제 꾸준히 풀이
* 다양한 알고리즘 및 자료구조 학습
* 코드 리뷰 및 복습을 위한 풀이 기록
* 코딩 테스트 대비

## 📂 Repository Structure

```text
leetcode/
├── Easy/
├── Medium/
├── Hard/
└── README.md
```

각 문제 디렉터리는 다음과 같은 구조를 가집니다.

```text
0001_Two_Sum/
├── solution.cpp
├── solution.py
└── README.md
```

* `solution.*` : LeetCode 제출 코드
* `README.md` : 풀이 아이디어 및 시간·공간 복잡도 정리
